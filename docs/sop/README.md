# SOP manuals

Six India SOP manuals (6 Oct 2026) that the product is measured against. ADR 058 and
`docs/templates-and-cover.md` build on them.

| File                               | Manual                                     |
| ---------------------------------- | ------------------------------------------ |
| `standalone-restaurant.pdf`        | Standalone Restaurant (fine, casual, café) |
| `bar-pub-microbrewery.pdf`         | Bar, Pub and Microbrewery                  |
| `cloud-kitchen-virtual-brands.pdf` | Cloud Kitchen and Virtual Brands           |
| `franchise.pdf`                    | Food & Hospitality Franchise               |
| `full-service-hotel-resort.pdf`    | Full-Service Hotel & Resort                |
| `qsr-chain.pdf`                    | QSR Chain                                  |

`sop-vs-app.html` compares them with the app as it was after #73: in the SOPs and built the
same way, not built, built differently, and built but not in the SOPs. Open it in a browser.
