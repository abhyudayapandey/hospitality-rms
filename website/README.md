# Hey Senior website

The marketing site: one static page (`index.html`, hash-routed pages: Home, What Senior keeps,
Plans, Trust, Get a Senior, Privacy, Terms) and the item photos it shows (`img/`, from the
app's photo library, ADR 086). No build step: open `index.html` in a browser or serve the
folder from any static host.

It is a prototype: the demo form checks its fields and thanks the visitor, but sends nothing,
and Privacy and Terms are drafts for legal review. "Sign in" links to the app at its current
address. Hosting and the domain are not set up yet (ADR 161).
